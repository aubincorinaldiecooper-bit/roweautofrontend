# Frontend boundary

Use only the Beautiful UI design system from https://github.com/slev12397/beautiful-ui.

Preserve its foundation stylesheet, tokens, typography, spacing, radii, shadows, and interaction language. Compose from Beautiful UI atoms/primitives or semantic HTML styled only with those tokens and utilities. Do not add another component library or a parallel visual system. Iconoir is allowed because Beautiful UI already depends on it. Any change that introduces a second design system is a regression.
